# alibabacloudstack_cspprivate_hsm_group

Manages Alibaba Cloud HSM Group, used for creating and managing Hardware Security Module clusters.

## Example Usage

### Basic Usage

```hcl

variable "name" {
  default = "tf_hsm_group1476"
}

data "alibabacloudstack_zones" "default" {
  provider                    = alibabacloudstack-common
  available_resource_creation = "VSwitch"
}

data "alibabacloudstack_cspprivate_hsm_vendors" "default" {
}

resource "alibabacloudstack_vpc" "vpc" {
  provider   = alibabacloudstack-common
  vpc_name   = var.name
  cidr_block = "192.168.0.0/16" # VPC CIDR block
}

resource "alibabacloudstack_vswitch" "vsw" {
  provider          = alibabacloudstack-common
  vpc_id            = alibabacloudstack_vpc.vpc.id
  cidr_block        = "192.168.0.0/24" # VSwitch CIDR block
  availability_zone = data.alibabacloudstack_zones.default.zones.0.id
}

resource "alibabacloudstack_vpc" "vpc1" {
  provider   = alibabacloudstack-common
  vpc_name   = var.name
  cidr_block = "192.168.0.0/16" # VPC CIDR block
}

resource "alibabacloudstack_vswitch" "vsw1" {
  provider          = alibabacloudstack-common
  vpc_id            = alibabacloudstack_vpc.vpc1.id
  cidr_block        = "192.168.0.0/24" # VSwitch CIDR block
  availability_zone = data.alibabacloudstack_zones.default.zones.0.id
}

resource "alibabacloudstack_cspprivate_hsm_instance" "default" {
  product_code   = data.alibabacloudstack_cspprivate_hsm_vendors.default.vendors.0.products.0.code
  vendor_code    = data.alibabacloudstack_cspprivate_hsm_vendors.default.vendors.0.code
  vsm_type       = "gvsm"
  zone_id        = data.alibabacloudstack_zones.default.zones.0.id
  alias_name     = "${var.name}0"
  vpc_id         = alibabacloudstack_vpc.vpc.id
  vpc_cidr_block = alibabacloudstack_vpc.vpc.cidr_block
  vswitch_id     = alibabacloudstack_vswitch.vsw.id
  ip             = "192.168.0.100"
}

resource "alibabacloudstack_cspprivate_hsm_instance" "default1" {
  product_code   = data.alibabacloudstack_cspprivate_hsm_vendors.default.vendors.0.products.0.code
  vendor_code    = data.alibabacloudstack_cspprivate_hsm_vendors.default.vendors.0.code
  vsm_type       = "gvsm"
  zone_id        = data.alibabacloudstack_zones.default.zones.0.id
  alias_name     = "${var.name}1"
  vpc_id         = alibabacloudstack_vpc.vpc1.id
  vpc_cidr_block = alibabacloudstack_vpc.vpc1.cidr_block
  vswitch_id     = alibabacloudstack_vswitch.vsw1.id
  ip             = "192.168.0.101"
}


resource "random_password" "password" {
  count            = 1
  length           = 12
  special          = true
  override_special = "!@#$^&*()_"
  min_lower        = 1
  min_upper        = 1
  min_numeric      = 1
}



resource "alibabacloudstack_cspprivate_hsm_group" "default" {
  zone_ids = [
    "${alibabacloudstack_cspprivate_hsm_instance.default.zone_id}"
  ]
  password  = random_password.password.0.result
  hsm_count = "3"
  hsm_list = [
    "${alibabacloudstack_cspprivate_hsm_instance.default.id}",
    "${alibabacloudstack_cspprivate_hsm_instance.default1.id}"
  ]
}
```

## Argument Reference

The following arguments are supported:

* `password` - (Required, Forces new resource when changed) Initialization password for the HSM Group. Used for initializing the security credentials of the HSM Group, the length must comply with the password policy requirements.
* `hsm_count` - (Optional, Forces new resource when changed) Number of HSM instances. Specifies the number of HSM instances in the HSM Group, the minimum value is 1. Changing this parameter requires rebuilding the entire HSM Group.
* `zone_ids` - (Optional, Forces new resource when changed) List of zone IDs. Specifies the collection of zone IDs where HSM instances are deployed, in the format of a JSON array string (e.g., `["cn-wulan-env17e-amtest17001-a"]`). Changing this parameter requires rebuilding the entire HSM Group.
* `hsm_list` - (Optional) List of HSM instance IDs. Specifies the collection of existing HSM instance IDs to be added to the HSM Group, in the format of a JSON array string (e.g., `["hsm-xxx"]`). Supports dynamic updates without rebuilding the resource.

## Attributes Reference

The following attributes are exported:

* `id` - ID of the HSM Group (same as `group_name`).
* `create_time` - Creation time of the HSM Group, in ISO 8601 standard time string format.
* `group_name` - Name of the HSM Group, automatically generated by the system.
* `security_level_tag` - Security level tag, indicating the security level of the HSM Group (e.g., "public", "secret", etc.).
* `status` - Current status of the HSM Group (e.g., "uninitialized" indicates not initialized).
* `update_time` - Last update time of the HSM Group, in ISO 8601 standard time string format.
* `vpc_id` - VPC ID associated with the HSM Group, representing the network environment where HSM instances are deployed.
