# alibabacloudstack_prometheus_v2_contact

Manages contact resources for Alibaba Cloud Prometheus v2 monitoring service, used to configure alert notification recipients.

## Example Usage

### Basic Contact Configuration

```hcl
variable "name" {
  default = "tfacc-10446"
}

resource "alibabacloudstack_prometheus_v2_contact" "default" {
  mail     = "test@example.com"
  username = var.name
  mobile   = "13812345678"
}
```

## Argument Reference

The following arguments are supported:

* `mail` - (Required) The email address of the contact for receiving alert notifications. The email format must comply with standard specifications.
* `mobile` - (Required) The mobile phone number of the contact for SMS alert notifications. Must be an 11-digit mainland China mobile number.
* `username` - (Required) The unique identifier name of the contact, with a length of 1-64 characters, supporting Chinese characters, letters, numbers, and underscores.

## Attributes Reference

The following attributes are exported:

* `id` - The unique system identifier ID of the contact, automatically generated by the Prometheus service.

## Import

Contact can be imported using the contact ID, e.g.

```
$ terraform import alibabacloudstack_prometheus_v2_contact.example 12345
```
