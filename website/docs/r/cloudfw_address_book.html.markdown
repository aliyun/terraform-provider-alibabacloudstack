# alibabacloudstack_cloudfw_address_book

This resource manages IP or port address books in Alibaba Cloud Cloud Firewall.

## Example Usage

### Basic Usage

```hcl
variable "name" {
  default = "tf-testacc-addrbook-75750"
}

resource "alibabacloudstack_cloudfw_address_book" "default" {
  address_list = [
    "8888",
    "9999"
  ]
  group_type  = "port"
  group_name  = var.name
  description = var.name
}
```

## Argument Reference

The following arguments are supported:

* `group_name` - (Required, Forces new resource) The name of the address book. The name must comply with Cloud Firewall requirements and cannot contain special characters.
* `group_type` - (Required, Forces new resource) The type of the address book. Valid values: `ip` (IP address book), `port` (port address book).
* `description` - (Required) The description of the address book. Used to explain the purpose or content of the address book.
* `address_list` - (Required) The list of addresses. Must contain at least one address. For IP address books, the format is CIDR (e.g., 192.168.1.0/24). For port address books, the format is port numbers (e.g., 80,443).

## Attributes Reference

The following attributes are exported:

* `id` - The resource ID in the format "{group_type}:{group_uuid}".
* `address_list_count` - The total number of addresses in the address book.
* `auto_add_tag_ecs` - The status of automatic ECS tagging. 0 indicates disabled, 1 indicates enabled.
* `global` - The global flag. 0 indicates a non-global address book, 1 indicates a global address book.
* `group_uuid` - The unique identifier of the address book, a UUID generated by the Cloud Firewall system.
* `reference_count` - The total number of references, indicating how many times the address book is referenced by rules.
