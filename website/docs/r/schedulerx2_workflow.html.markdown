# alibabacloudstack_schedulerx2_workflow

Manages Schedulerx2 workflow resources, used for creating, configuring, and scheduling timed task workflows.

## Example Usage

### Basic Usage

```hcl

variable "name" {
  default = "tf-test97924"
}


resource "alibabacloudstack_schedulerx2_app_group" "example" {
  group_id        = "${var.name}.terra"
  app_name        = var.name
  description     = var.name
  max_jobs        = 30
  max_concurrency = 10
  metrics_threshold {
    load5       = 10
    heap5_usage = 100
    disk_usage  = 100
  }
  monitor_config {
    send_channel = "mail,ding"
    alarm_type   = "CustomContacts"
  }
}



resource "alibabacloudstack_schedulerx2_workflow" "example" {
  time_expression = "34 14 14 */1 * ?"
  time_zone       = "PRC"
  max_concurrency = "1"
  group_id        = alibabacloudstack_schedulerx2_app_group.example.group_id
  name            = var.name
  description     = "Initial description"
  time_type       = "cron"
}
```

## Argument Reference

The following arguments are supported:

* `group_id` - (Required, ForceNew) The ID of the application group to which the workflow belongs. Changing this parameter will recreate the resource.
* `name` - (Required) The name of the workflow. Length must be 1-128 characters and cannot start with `http://` or `https://`.
* `description` - (Required) The description of the workflow. Length must be 1-256 characters and cannot start with `http://` or `https://`.
* `time_type` - (Required) The time trigger type. Valid values: `cron` (scheduled trigger) or `api` (API trigger).
* `time_zone` - (Required) The time zone configuration. Valid values: `PRC`, `Hongkong`, `Japan`, `Singapore`, `GTM`, `GTM-0` to `GTM-14` (including positive and negative time zones).
* `enabled` - (Optional) Whether to enable the workflow. Set to `true` to enable, `false` to disable. Default value: `false`.
* `max_concurrency` - (Optional) The maximum number of concurrent tasks. Valid values: 1-1000.
* `namespace` - (Optional) The namespace. Default value: `system_namespace`.
* `time_expression` - (Optional) The time expression. Takes effect when `time_type` is `cron`, must comply with Quartz cron expression specification (e.g., `"34 14 14 */1 * ?"`).

## Attributes Reference

The following attributes are exported:

* `id` - The workflow ID (same as `workflow_id`).
* `workflow_id` - The workflow ID (a unique identifier generated by the system).

## Import

Schedulerx2 Workflow can be imported using the workflow ID, e.g.

```
$ terraform import alibabacloudstack_schedulerx2_workflow.example 12345
```
