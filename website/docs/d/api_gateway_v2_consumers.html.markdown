# alibabacloudstack_api_gateway_v2_consumer

Query information about API Gateway v2 consumers. API Gateway v2 consumers are authentication entities used to access APIs, supporting multiple authentication methods including API Key, Basic Auth, JWT, OAuth2.0, etc.

## Example Usage

```hcl

variable "name" {
  default = "tf-testacc2388364"
}

data "alibabacloudstack_api_gateway_v2_instance_types" "default" {
  sorted_by = "CPU"
}

resource "alibabacloudstack_api_gateway_v2_instance" "default" {
  instance_name      = var.name
  node_number        = "1"
  instance_class     = data.alibabacloudstack_api_gateway_v2_instance_types.default.instance_types[0].id
  broker_engine_type = "SCG"
  deploy_mode        = "custom"
}

resource "alibabacloudstack_api_gateway_v2_consumer" "default" {
  auth_type      = "1"
  app_name       = var.name
  description    = var.name
  key            = "root"
  password       = "admin"
  gw_instance_id = alibabacloudstack_api_gateway_v2_instance.default.id
  groups         = ["test"]
}

data "alibabacloudstack_api_gateway_v2_consumers" "default" {
  gw_instance_id = alibabacloudstack_api_gateway_v2_consumer.default.gw_instance_id
  appid          = alibabacloudstack_api_gateway_v2_consumer.default.app_id
}

```

## Argument Reference

The following arguments support filtering query results:

- **gw_instance_id** (Required): The gateway instance ID, used to specify the API Gateway instance to query.

- **appid** (Optional): The application ID, used to precisely filter consumers with a specific application ID.

- **ids** (Optional): A list of consumer IDs, in the format `{gwInstanceId:appId}`, used to filter consumers with specified IDs.

- **name_regex** (Optional): A regular expression for the application name, used to filter consumers by matching the application name with a regular expression.

## Attributes Reference

The following attributes are exported:

- **id** (String): The consumer ID, in the format `{gwInstanceId:appId}`, which is the unique identifier of the resource.

- **access_key** (String): The access key, returned when the authentication type is CSB.

- **app_code** (String): The application code, returned when the authentication type is appgw-app.

- **app_id** (String): The application ID, a unique identifier generated by the API Gateway system.

- **app_name** (String): The application name, specified when creating the consumer.

- **app_secret** (String): The application secret, key information used for API authentication.

- **auth_type** (Integer): The authentication type code, where 5=API_KEY, 1=BASIC, 3=JWT, 2=OAuth2.0, 6=API_GATEWAY, 7=CSB_AUTH.

- **auth_type_name** (String): The authentication type name, such as "API_KEY", "BASIC", "JWT", etc.

- **description** (String): The description of the consumer.

- **enable** (Boolean): Whether the consumer is enabled, true means enabled, false means disabled.

- **expire_time** (Integer): The expiration time in milliseconds, representing the validity period of the token.

- **groups** (List): A list of groups to which the consumer belongs, the API groups to which the consumer belongs.

- **key** (String): The authentication key, which has different meanings for different authentication types, such as the key in API Key authentication, the username in Basic authentication, etc.

- **oauth2_payload** (List): OAuth2.0 authentication payload information, containing the following sub-attributes:
  - **authorization_code** (Boolean): Whether the authorization code grant type is enabled
  - **client_credentials** (Boolean): Whether the client credentials grant type is enabled
  - **implicit_grant** (Boolean): Whether the implicit grant type is enabled
  - **password_grant** (Boolean): Whether the password grant type is enabled
  - **token_expiration** (Integer): Token expiration time in seconds
  - **refresh_token_expiration** (Integer): Refresh token expiration time in days
  - **pkce** (Boolean): Whether PKCE (Proof Key for Code Exchange) is enabled
  - **scopes** (String): A list of scopes, comma-separated
  - **client_id** (String): OAuth2.0 client ID
  - **client_secret** (String): OAuth2.0 client secret
  - **redirect_uris** (String): A list of redirect URIs, comma-separated

- **password** (String): The password, returned when the authentication type is Basic.

- **request_header** (String): The request header, the name of the request header used in OAuth2.0 authentication.

- **secret_key** (String): The secret key, returned when the authentication type is CSB.

- **token** (String): The token, token information generated by different authentication types.

- **use_white_list** (Boolean): Whether the whitelist is enabled, true means enabled, false means disabled.
