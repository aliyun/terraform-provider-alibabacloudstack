# alibabacloudstack_kvstore_parameter_groups

Queries the list of parameter templates for ApsaraDB for Redis (KVStore). This data source is used to retrieve information about created parameter templates, including parameter template ID, name, description, engine version, etc.

## Example Usage

```hcl
variable "name" {
  default = "tf-kvparamgroup34466"
}

resource "alibabacloudstack_kvstore_parameter_group" "default" {
  character_type       = "logic"
  parameter_group_name = var.name
  engine_version       = "7.0"
  parameter_group_desc = var.name
  parameters {
    param_name = "resp_version"
    value      = "3"
  }
  parameters {
    param_name = "rt_threshold_ms"
    value      = "400"
  }
  parameters {
    param_name = "#no_loose_check-whitelist-always"
    value      = "yes"
  }
}

data "alibabacloudstack_kvstore_parameter_groups" "default" {
  name_regex = alibabacloudstack_kvstore_parameter_group.default.parameter_group_name
}
```

## Argument Reference

The following arguments are supported:

* `character_type` (String) - The character type of the parameter template. Valid values: `logic` (logical parameter template), `normal` (normal parameter template).
* `engine_version` (String) - The engine version of the parameter template. Example: `7.0`.
* `ids` (List) - A list of parameter template IDs used to filter results. Each element in the list is a string.
* `name_regex` (String) - A regular expression for the parameter template name used to filter results.

## Attributes Reference

The following attributes are exported:

* `id` (String) - The unique identifier of the data source, generated by hashing the filtered parameter template IDs.
* `character_type` (String) - The character type of the parameter template.
* `create_time` (String) - The creation time of the parameter template, in ISO 8601 standard time format.
* `engine_version` (String) - The engine version of the parameter template.
* `groups` (List) - A list of matching parameter templates. Each element contains the following attributes:
  * `character_type` (String) - The character type of the parameter template.
  * `create_time` (String) - The creation time of the parameter template.
  * `engine_version` (String) - The engine version of the parameter template.
  * `id` (String) - The parameter template ID, same as `parameter_group_id`.
  * `is_dynamic` (Integer) - Whether the parameter is dynamic. 1 indicates yes, 0 indicates no.
  * `parameter_group_desc` (String) - The description of the parameter template.
  * `parameter_group_id` (String) - The ID of the parameter template.
  * `parameter_group_name` (String) - The name of the parameter template.
  * `parameters` (List) - A list of parameters in the parameter template. Each element contains:
    * `param_name` (String) - The name of the parameter.
    * `value` (String) - The value of the parameter.
  * `type` (Integer) - The type of the parameter template.
* `names` (List) - A list of matching parameter template names.
* `parameter_group_desc` (String) - The description of the parameter template.
* `parameter_group_id` (String) - The ID of the parameter template.
* `parameter_group_name` (String) - The name of the parameter template.
* `type` (Integer) - The type of the parameter template.
