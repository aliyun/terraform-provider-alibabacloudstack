# alibabacloudstack_dns_gtm_addresspools

Queries the list of DNS GTM (Global Traffic Management) address pools in Alibaba Cloud. This data source retrieves information about created address pools and supports filtering by ID, name regular expression, type, and load balancing strategy.

## Example Usage

```hcl
variable "name" {
  default = "tfacc45249"
}

resource "alibabacloudstack_dns_gtm_addresspool" "default" {
  name         = var.name
  type         = "A"
  lba_strategy = "RATIO"

  addrs {
    value      = "192.168.1.1"
    mode       = "SMART"
    lba_weight = 20
  }

  addrs {
    value      = "127.0.0.1"
    mode       = "SMART"
    lba_weight = 80
  }
}

data "alibabacloudstack_dns_gtm_addresspools" "default" {
  name_regex = alibabacloudstack_dns_gtm_addresspool.default.name
}
```

## Argument Reference

The following arguments support filtering the query results:

### Optional
* `ids` (List of strings): List of address pool IDs for exact matching of specified address pools.
* `lba_strategy` (String): Filter condition for load balancing strategy. Valid values: `ALL_RR` (returns all addresses without weight), `RATIO` (returns addresses by weight).
* `name_regex` (String): Regular expression filter for address pool names, used for fuzzy matching of address pool names.
* `type` (String): Filter condition for address pool type. Valid values: `A` (IPv4 address), `AAAA` (IPv6 address), `CNAME` (domain name).

## Attributes Reference

The following attributes are exported:

* `id` (String): Unique identifier for the data source, generated by hashing the matched address pool IDs.
* `address_pools` (List): List of matched address pools. Each element contains the following attributes:
  * `addrs` (List): List of addresses in the address pool. Each element contains:
    * `available` (Boolean): Indicates whether the address is available.
    * `lba_weight` (Integer): Load balancing weight of the address.
    * `mode` (String): Address mode. Valid values: `SMART` (smart return), `ONLINE` (always online), `OFFLINE` (always offline).
    * `value` (String): Address value (IP or domain name).
  * `create_timestamp` (Integer): Creation timestamp of the address pool in seconds.
  * `id` (String): Unique identifier of the address pool.
  * `lba_strategy` (String): Load balancing strategy of the address pool. Valid values: `ALL_RR`, `RATIO`.
  * `name` (String): Name of the address pool.
  * `type` (String): Type of the address pool. Valid values: `A`, `AAAA`, `CNAME`.
  * `update_timestamp` (Integer): Last update timestamp of the address pool in seconds.
* `ids` (List of strings): List of matched address pool IDs.
