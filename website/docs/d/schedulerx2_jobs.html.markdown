# alibabacloudstack_schedulerx2_job

> SchedulerX2 job management

## Example Usage

```hcl
variable "name" {
  default = "tf-test96911"
}

resource "alibabacloudstack_schedulerx2_app_group" "example" {
  group_id        = "${var.name}.terra"
  app_name        = var.name
  description     = var.name
  max_jobs        = 30
  max_concurrency = 10
  monitor_config {
    send_channel = "mail,ding"
    alarm_type   = "CustomContacts"
  }
  contacts {
    username    = "test"
    user_email  = "123@123.com"
    dingding_ak = "testakkkkk"
  }
  metrics_threshold {
    load5       = 10
    heap5_usage = 100
    disk_usage  = 100
  }
}

resource "alibabacloudstack_schedulerx2_job" "example" {
  namespace                   = "system_namespace"
  group_id                    = alibabacloudstack_schedulerx2_app_group.example.group_id
  name                        = var.name
  job_type                    = "python"
  execute_mode                = "standalone"
  description                 = var.name
  priority                    = 5
  parameters                  = "testargs=1"
  max_attempt                 = 3
  attempt_interval            = 30
  max_concurrency             = 2
  time_type                   = 1
  time_expression             = "8 59 15 */1 * ?"
  content                     = "python test"
  monitor_timeout_enable      = true
  monitor_timeout_kill_enable = true
  monitor_fail_enable         = true
  monitor_miss_worker_enable  = true
  monitor_timeout             = 3600
}

data "alibabacloudstack_schedulerx2_jobs" "default" {
  name_regex = alibabacloudstack_schedulerx2_job.example.name
}
```

## Argument Reference

The following arguments are supported:

* `content` (String, Required): The job execution content, such as "python test" or a Java class path.
* `execute_mode` (String, Required): The job execution mode. Valid values include "standalone" (single-machine execution), "broadcast" (broadcast mode), etc.
* `group_id` (String, Required, Forces new resource when changed): The group ID to which the job belongs, used for job grouping management.
* `job_type` (String, Required): The job type. Valid values include "python", "java", "shell", etc.
* `name` (String, Required, Forces new resource when changed): The job name, used to identify the job.
* `priority` (Integer, Required): The job priority. A higher value indicates higher priority.
* `time_expression` (String, Required): The time expression. The format varies based on time_type, such as the cron expression "8 59 15 */1 * ?".
* `time_type` (String, Required): The time type. 1 indicates fixed frequency, 2 indicates cron expression, 3 indicates fixed time.
* `attempt_interval` (Integer, Optional): The interval between job retries in seconds. Default value: 30.
* `description` (String, Optional): The job description.
* `max_attempt` (Integer, Optional): The maximum number of retries when the job execution fails.
* `max_concurrency` (Integer, Optional): The maximum concurrency, controlling the number of instances that can execute the job simultaneously.
* `parameters` (String, Optional): The job parameters in the format "key1=value1 key2=value2".
* `xattrs` (String, Optional): Extended attributes, a JSON-formatted string used to store additional configurations.
* `monitor_config` (String, Optional): The monitoring configuration, a JSON-formatted string containing timeout, failure, and other monitoring settings.

## Attributes Reference

The following attributes are exported:

* `id` (String): The job ID, a unique identifier generated by the system.
* `app_group_id` (Integer): The application group ID, the identifier of the associated application group.
* `calendar` (String): The calendar configuration, used for scheduling on special dates.
* `clean_mode` (String): The cleanup mode, the resource cleanup policy after job execution completes.
* `contact` (String): Contact information, the contact notified when the job encounters an exception.
* `content_type` (Integer): The content type, identifying the format of the job content.
* `creator` (String): The creator ID, the user identifier of the job creator.
* `data_offset` (Integer): The data offset, used for data sharding processing.
* `gmt_create` (String): The job creation time in ISO8601 format.
* `gmt_modified` (String): The last modification time of the job in ISO8601 format.
* `monitor_fail_enable` (Boolean): Whether failure monitoring is enabled, triggering an alert when the job execution fails.
* `monitor_miss_worker_enable` (Boolean): Whether worker node loss monitoring is enabled, triggering an alert when a worker node goes offline.
* `monitor_timeout` (Integer): The timeout duration in seconds. If job execution exceeds this time, it is considered timed out.
* `monitor_timeout_enable` (Boolean): Whether timeout monitoring is enabled, triggering an alert when the job execution times out.
* `monitor_timeout_kill_enable` (Boolean): Whether timeout termination is enabled, automatically terminating the job when it times out.
* `resource` (String): The resource identifier, the resource information associated with the job.
* `template` (String): The template information, the template configuration used by the job.
* `timezone` (String): The time zone setting, the time zone used for job scheduling.
* `updater` (String): The updater ID, the user identifier of the last modifier of the job.
* `version` (Integer): The job version number, incremented each time the job is modified.
* `workflow_id` (String): The workflow ID, the identifier of the associated workflow.
